# DayOne

Context-aware developer onboarding, from machine setup to a first reviewable merge request.

DayOne turns a generic onboarding checklist into a live journey. It verifies the developer's actual environment, explains blockers in repository context, introduces the system through a real request flow, and preserves progress locally.

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm test
npm run lint
```

Built with React, vinext, and Cloudflare-compatible output.
