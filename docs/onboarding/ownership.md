# Onboarding ownership

DayOne keeps human escalation explicit. Asking the Guide is an in-product interaction; recording a help request saves context but does not notify anyone automatically.

## Repository path

- Code, API, and journey rules: the `ianjuantw/dayone` repository maintainer
- Hosting identity and D1 runtime: the configured Sites workspace
- First pull request review: the reviewer selected in the DayOne plan
- Environment blockers: record the failed doctor check, then share it manually with the chosen reviewer or maintainer

Every escalation should include the current journey step, the relevant task, the latest doctor run time, and expected versus actual behavior. Do not paste credentials, tokens, `.env` contents, or absolute home-directory paths.
